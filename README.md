# מערכת ניהול דרישות תשלום – אב-טיפוס (iPlan Vibe Coding Challenge)
**מוגש עבור: מינהל התכנון – אגף בכיר טכנולוגיות דיגיטליות ומידע**

## 1. תיאור הפתרון
אב-טיפוס למערכת Web מתקדמת המיועדת לאוטומציה ושקיפות בתהליכי הגשת ואישור דרישות תשלום של יועצים חיצוניים. המערכת מחליפה תהליכים ידניים בממשק דיגיטלי המאפשר מעקב הדוק אחר לוחות זמנים ומניעת חריגות תקציביות.

## 2. דגשי פיתוח וחווית משתמש (UX/UI)
מעבר לדרישות הסף, הטמעתי פתרונות הממוקדים ביעילות תפעולית ובדיוק נתונים:
* **ניהול נתונים מתקדם:** הוספת יכולות מיון (Sorting) וסינון (Filtering) על גבי כל עמודות הטבלה הרלוונטיות (תאריך, סכום, דחיפות), המאפשרות איתור מהיר של מידע בנפחי נתונים גדולים.
* **ניהול SLA חכם:** חיווי ויזואלי בולט (אדום) לחריגות מעל 90 יום, כולל התרעות מוקדמות למניעת צווארי בקבוק.
* **מנגנון "סגירת מעגל" (Clarification Loop):** אפשרות להחזרת בקשות להבהרות ועריכתן מחדש על ידי היועץ תוך שמירה על רצף התהליך (State Persistence).
* **ולידציה ושלמות נתונים:** מניעת הזנת סכומים לא תקינים ומשוב מיידי למשתמש (Toasts) בעברית מלאה.
* **רספונסיביות מלאה:** התאמה לכל סוגי המסכים לצורך מעקב ואישור בקשות גם מהשטח.

## 3. מבט טכנולוגי וראייה לעתיד
הפרויקט פותח ב-React תוך שימוש בכלי AI מתקדמים (Lovable.dev). בתכנון גרסת ה-Production יושמו המרכיבים הבאים:
* אבטחת מידע וניהול סשנים מאובטחים באמצעות **JWT**.
* אימות הרשאות מבוסס תפקיד (RBAC) בצד השרת.
* שימוש במסד נתונים רלציוני המבוסס על Enums לניהול סטטוסים ומניעת שגיאות לוגיות.

## 4. הנחיות הפעלה
במערכת קיים כפתור "החלף תפקיד" בסרגל העליון המאפשר מעבר מיידי בין ממשק היועץ (הגשה ומעקב) לבין ממשק עובד הארגון (בדיקה, אישור ובקרה).
